# TIC Event Suite for Vectorworks (0.7.0)

Lets your own Claude work in your Vectorworks drawing through the TIC Event Suite: draw, place TIC objects, change their settings, organise layers and sheets, and run the suite's reports and jobs.

You need: Vectorworks with the TIC Event Suite on the Pro plan, the TIC-ES Control Panel open with Claude link on, and to sign in to the connector with your licence the first time.

What Claude reads from your drawing, pictures included, passes through TIC's connector to Claude. Claude never runs scripts in your Vectorworks. Privacy notice: https://theimaginationcollaborative.online/claude/privacy

Claude can get things wrong. Save your drawing before big changes and check every result. Planning figures are guidance only and must be checked by a relevant professional against your local rules.

This plugin holds no TIC code. It carries the connector's address and instructions for Claude. Everything Claude does runs inside your Vectorworks through the suite.

## Install

In Claude: Customize, Plugins, Add marketplace, enter TheImaginationCollaborative/tic-claude-plugins, then install TIC Event Suite for Vectorworks.

In Claude Code:

    /plugin install tic-event-suite-for-vectorworks --marketplace TheImaginationCollaborative/tic-claude-plugins
