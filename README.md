# TIC Event Suite plugins for Claude

Plugins from The Imagination Collaborative for using Claude with the TIC Event Suite for Vectorworks.

## Install

In Claude, open Customize, then Plugins, choose Add marketplace, and enter this repository's address. Then install TIC Event Suite for Vectorworks.

## Requirements

Vectorworks 2027 with the TIC Event Suite on the Pro plan, and the TIC-ES Control Panel open with Claude link on.
